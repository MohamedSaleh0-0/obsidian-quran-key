# Quran Key

Advanced contextual Quran citation, precise word-index snippet trimming, and analytical dashboards for Obsidian.

## Features

- Contextual Parsing: Scan active text selections, curly braces, or chapters and verses to inject verses atomically.
- Stateful Toggle: Press the evaluation hotkey consecutively to seamlessly switch between full verses and specific search boundaries.
- Analytics Dashboard: View comprehensive metrics directly under the search bar including total matches and density calculations.
- Academic Commands: Clean diacritics, strip references, or instantly convert citations into Pandoc-compliant footnotes.

## Installation

1. Search for Quran Key in the Obsidian Community Plugins tab.
2. Enable the plugin in your vault settings.
3. Ensure your study data file is placed in the designated plugin configurations directory.
